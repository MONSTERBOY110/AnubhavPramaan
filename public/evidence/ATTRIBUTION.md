# Evidence example images

These images are openly licensed demonstration examples for the assessor UI, not candidate evidence. They show what photo evidence for each performance criterion can look like, so the checklist and its AI evidence hints can be demonstrated without using any real candidate's photos. Every file comes from Wikimedia Commons; the licence and author below were read from each file's own Commons page. Each file was downscaled to at most 1600 px on the longest side, saved as JPEG, and stripped of EXIF and other embedded metadata. Modified versions of CC BY-SA files are shared under the same licence as the original. Photos that include people show only their hands; no faces are visible.
